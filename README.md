PRD 요구사항에 맞추어 설계 및 제작된 반응형 모던 할 일 관리 웹 애플리케이션입니다.  
별도의 Node.js, Python, 빌드 도구 설치 없이 **브라우저에서 `index.html`을 더블 클릭하는 것만으로 즉시 실행**됩니다.

---

## 🚀 빠른 시작 (실행 방법)

1. 폴더 내의 [`index.html`](file:///c:/Users/김태윤/Desktop/Workspace/todolist/index.html) 파일을 더블 클릭하여 크롬, 엣지(Edge) 등 원하는 웹 브라우저에서 엽니다.
2. 바로 할 일을 추가하고 관리할 수 있습니다!

---

## ✨ 구현된 핵심 기능

### 1. 할 일 기본 관리 (CRUD)
- **빠른 추가**: 상단 입력창에 할 일을 입력하고 `Enter` 키 또는 `추가` 버튼을 누르면 즉시 등록됩니다.
- **마감일 / 우선순위 / 카테고리**:
  - 마감일: 오늘 마감, D-day, 기한 지남 시 직관적인 뱃지 표시
  - 우선순위: 높음(🔴), 보통(🟡), 낮음(🟢)
  - 카테고리 태그: 업무, 개인, 공부, 기타

### 2. 완료 체크 & 하단 완료 목록 분리 (요구사항 집중 구현)
- 할 일의 체크박스를 클릭하면 **취소선 스타일과 함께 하단 `[완료된 목록]` 전용 영역으로 자동 이동**합니다.
- 하단 완료 목록에서 체크박스를 다시 해제하면 언제든 **`진행 중인 할 일`로 즉시 복구**됩니다.
- **아코디언 접기/펼치기**: `완료된 목록` 헤더를 클릭하여 접어두거나 펼쳐서 확인할 수 있어 목록이 길어져도 깔끔합니다.
- **완료 항목 비우기**: 완료된 항목만 일괄 삭제할 수 있는 기능 지원.

### 3. 필터링, 정렬 및 실시간 검색
- **상태 탭**: `전체`, `진행 중`, `완료됨`
- **카테고리 필터**: 업무, 개인, 공부, 기타별 모아보기
- **실시간 검색**: 제목 및 세부 메모 키워드 검색 (완료된 목록 내에서도 일치하는 항목 즉시 탐색)
- **정렬 옵션**: 등록 최신순, 마감일 빠른순, 우선순위 높은순

### 4. 상세 보기 & 수정 패널 (모달)
- 할 일 카드 또는 수정 아이콘을 클릭하면 상세 모달이 열립니다.
- 긴 메모(설명) 작성 및 수정
- **하위 체크리스트(Subtasks)**: 세부 단계별 체크리스트를 추가하고 개별 체크 가능

### 5. 달성 현황 대시보드
- 상단에 실시간 완료율(%)과 프로그레스 바(Progress Bar) 제공
- 오늘 날짜 자동 표시

### 6. 3단 테마 모드 (라이트 / 중간 / 다크) & 로컬 영속성
- 우측 상단 테마 버튼을 클릭하여 **☀️ 라이트 모드 ➡️ 🌓 중간 모드 ➡️ 🌙 다크 모드**로 순환 전환 가능
  - **라이트 모드**: 화사하고 깨끗한 화이트 톤
  - **중간 모드 (신규)**: 라이트의 눈부심과 다크의 어두움을 절충한 눈이 편안한 소프트 슬레이트 그레이 톤
  - **다크 모드**: 깊이 있고 차분한 딥 네이비/다크 톤
- 모든 데이터와 선택한 테마는 브라우저 `localStorage`에 자동 보관되어 창을 닫아도 안전하게 유지됩니다.
